# OTFT特性解析スキル

B1500A測定データからOTFT（有機薄膜トランジスタ）の特性を解析し、論文用パッケージを作成します。

## 解析項目

1. **飽和移動度 (μ_sat)**: 最大傾斜法で算出
2. **サブスレッショルドスイング (SS)**: 線形フィット法で算出
3. **On/Off電流比**: 最大/最小電流
4. **閾値電圧 (Vth)**: √Id vs Vgのx切片

## 入力

ユーザーに以下を確認してください：

1. **データフォルダのパス**: B1500A CSVファイルが格納されたディレクトリ
2. **解析名**: 出力フォルダ名（例: ss, darklight, ltw）
3. **デバイスパラメータ**（必要に応じて）:
   - チャネル幅 W (デフォルト: 1000 μm)
   - チャネル長 L (デフォルト: 50 μm)
   - ゲート容量 Ci (デフォルト: 5.49 nF/cm² for Parylene 500nm)

## 処理フロー

1. **データ確認**: フォルダ内のCSVファイルを確認し、ファイル名パターンを解析
2. **解析スクリプト作成**: `analysis/<解析名>_analysis.py` を作成
3. **実行**: スクリプトを実行して結果を取得
4. **グラフ作成**: 論文クオリティ（Nature風）のグラフを生成
5. **パッケージ作成**: `publication/<解析名>/` に以下を出力:
   - PDFグラフ
   - 結果CSV
   - README_論文用.md（キャプション・本文例・表データ）

## 出力フォルダ構造

```
Research-Data/
├── processed/<解析名>/
│   └── <解析名>_results.csv
├── figures/<解析名>/
│   └── Figure_*.pdf
└── publication/<解析名>/
    ├── Figure_*.pdf
    ├── <解析名>_results.csv
    └── README_論文用.md
```

## グラフスタイル

- フォント: Arial, 8-9pt
- 解像度: 600 dpi
- マーカー: 白抜き
- 軸: 内向きtick、上・右スパイン削除
- カラー: 黒 (#000000) + 赤 (#C00000)

## B1500A CSVフォーマット

```
DataName, Vg, Vd, Ig, Id, Is
DataValue, 10.0, -10, 1.23e-9, ...
```

- `DataName,` で始まる行からカラム名を取得
- `DataValue,` で始まる行からデータを取得
- encoding='utf-8-sig' でBOMを処理

## 使用例

```
/otft-analysis
```

→ データフォルダのパスを入力
→ 解析名を入力
→ 自動で解析・グラフ作成・パッケージ生成
